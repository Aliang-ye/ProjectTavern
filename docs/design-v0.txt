============================================================
一、项目总览
============================================================

1.  产品定位

Project Tavern 是一个 Android 优先的跨模型 AI Character / RPG Client。

核心理念： Bring your own AI. Bring your own world.

用户自己提供第三方 AI API Key，App 本身不提供 AI 推理、不提供模型、不做
API 中转代理。

App 负责： - Character 管理 - World Book 管理 - Story / RPG 管理 -
Chat - Generation - Branch - Memory - Prompt 构建 - Context 管理 -
多模型 Provider - 本地数据管理 - Import / Export

V0
不开放社区，不提供公共或个人社区内容发布能力，只保留表面入口和未来架构占位。

2.  V0 产品原则

第一： AI 是用户自己的，Tavern 是用户控制 AI 的工具。

第二： Character、World、Story、Memory、Chat 必须解耦。

第三： 本地优先，V0 尽量不依赖自己的后端。

第四： V0 宁可少做，也不要破坏核心架构。

第五： 社区、商城、账号、云同步等全部延后。

============================================================ 九、永久
Companion 系统
============================================================

用户可以把 Character 单独带进 Story。

例如：

Alice 原本属于： Fantasy World

用户创建：

我的冒险

选择：

Alice -> 永久陪伴

于是：

Story | +– Main Character | +– Alice [COMPANION]

Companion 不意味着每次请求都发送完整 Character Card。

Context Engine 根据当前场景决定：

-   是否激活
-   激活程度
-   使用多少上下文
-   是否需要完整设定

例如当前正在和国王谈判：

Alice 可能只需要作为“当前陪同角色”存在。

当用户开始与 Alice 对话时：

提高 Alice 的 Context 权重， 必要时加载更多 Character 信息。

V0 的简化实现：

每个 Companion 有：

-   enabled
-   priority

并在 Prompt Builder 中生成简化 Companion Context。

未来再加入： - Location - Relationship - Status - Activity - Dynamic
Memory

十二、Prompt Engine
============================================================

Chat -> Context Builder -> Prompt Builder -> Provider -> AI API

PromptBlock：

-   type
-   content
-   priority
-   position
-   tokenEstimate
-   enabled

类型：

SYSTEM GLOBAL PROMPT CHARACTER SYSTEM CHARACTER DESCRIPTION PERSONALITY

HISTORY USER MESSAGE

============================================================
十三、Context Manager
============================================================

Context Manager 负责：

-   Context Limit
-   Token Estimate
-   History 截断
-   World Book 截断
-   Memory 保留
-   Response Budget

示例：

Context Limit = 32K

System 2K Character 3K World 4K Memory 2K History 16K Response 5K

优先保留：

1.  System
2.  Current User Message
3.  Character Core
4.  Memory
5.  World Book
6.  Recent History
7.  Old History

旧 History：

Recent History 保持完整。

更早内容进入 Summary。

============================================================
三十五、最终产品哲学
============================================================

Project Tavern 不应该首先成为：

“一个什么都有的 AI 平台”。

而应该首先成为：

“最好用的个人 AI Tavern Client”。

用户打开 App：

我有自己的模型。 我有自己的角色。 我有自己的世界。 我有自己的故事。
我可以随时切换模型。 我可以让角色长期陪伴。 我可以让剧情产生无数分支。
我的数据属于我。

最终核心：

Character + World + Story + Companion + Memory + Branch + BYOK + Prompt
Engine

构成 Project Tavern 的核心产品壁垒。
