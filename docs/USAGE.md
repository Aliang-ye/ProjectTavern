# 使用说明

## 第一次打开

1. 底栏点 **设置**。
2. **主题**：深色烛火、浅色原木纸张、或跟随系统。
3. **语言**：中文或 English。界面和模型回复同一套，不会中英夹杂。
4. **用户主体**：填你在故事里的名字和人设。会替换 `{{user}}`。
5. **API 配置** → 新配置：
   - OpenAI 兼容：填接口地址、模型名、Key（DeepSeek / xAI / Groq 都走这一路）。
   - Claude：填 Anthropic 或兼容 Messages 的地址、模型名、Key。
6. 点一条配置，星号表示当前使用的那条。

## 单独对话

不必先建故事。

1. 打开 **角色**，点某个角色，或列表上的「单独对话」。
2. 会带上该角色的**默认世界书**。
3. 底栏 **对话** 里，单独对话和故事对话是分开列的。

## 世界书

六个栏目会作为世界底色**始终注入**（有字才注入）：

- 概况
- 世界地理
- 历史
- 制度
- 人文
- 个人补充设定

关键词**条目**按当前对话文本匹配。点「条目测试」可贴一段上下文，看哪些条目会被注入（测试时忽略概率骰子）。

## 故事

长期 RPG 存档：

1. 新建故事，勾选世界书。
2. 把角色设为主角 / 同伴 / 路人。
3. 从故事里开一场对话。同伴描述会进提示词。

## 对话里能做什么

- 输入框写行动，发送。生成中点停止，已收到的字会留下。
- 长按区域（界面上的文字按钮）：复制、重写、编辑、从这里分叉、删除。
- 顶部切换 **生成模式**（小说 / 创意 / 快速 / 推理）。
- **调试**：看本轮注入了哪些世界条目。设置里打开「开发者模式」后，调试默认展开。
- Generation 左右翻：同一次回复的多个版本。
- 分支左右翻：同一父消息下的分叉。

## 备份

设置 → 数据：

- **导出备份**：JSON，不含 Key。
- **恢复备份**：用备份覆盖角色 / 世界 / 故事 / 对话，**保留当前 Key**。
- **恢复示例数据**：清空本机酒馆，回到艾莉丝示例。

## 隐私

- 没有账号、没有云、没有统计。
- 网络只在你点发送时，直连你填的 API 地址。
- 卸载应用会删掉本机 `tavern.json`。先导出备份。
